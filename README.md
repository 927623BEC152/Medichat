# MediChatbot 🏥💊

MediChatbot is a **Java Swing + MySQL based healthcare assistance application** that helps users identify diseases based on symptoms and provides medical recommendations such as medicines, nutrition plans, hydration advice, and secure account management.

This project was developed as a **DBMS + Java application project** to demonstrate healthcare automation using database management concepts.

---

## Features

- User Signup  
- User Login  
- Forgot Password  
- OTP Email Verification  
- Password Reset  
- Symptom Checker  
- Disease Detection  
- Medicine Recommendation  
- Nutrition Advice  
- Logout Feature  
- Medical Disclaimer  

---

## Technologies Used

- Java  
- Java Swing  
- MySQL  
- Eclipse IDE  
- Google SMTP (for OTP emails)

---

## Database Tables

- users  
- symptoms  
- diseases  
- medicines  
- disease_symptoms  
- prescriptions  
- nutrition  
- consultation_history  

---

## How to Run

1. Clone the repository  
2. Import MySQL database  
3. Add required JAR files:
   - MySQL Connector  
   - Java Mail  
   - Activation JAR  
4. Configure email credentials in `EmailSender.java`  
5. Run `Main.java`
